## 👨‍💻 About Me

I'm a backend software engineer focused on building **scalable, efficient, and reliable systems**. I work mostly with **Java and Spring Boot**, use **Go** where raw performance matters, and reach for **Spring WebFlux** when a reactive, non-blocking design fits. My goal is simple: APIs and services that stay fast and maintainable under real-world load.
